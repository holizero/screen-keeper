# 공개 전 검토 기록 — 1.0.0

최초 공개 배포 1.0.0의 검토 기록입니다. 공개 전 내부 개발 번호를 정리하고, 세션 전환·설정 손상 방지·실패 처리·공개 배포 자료를 포함했습니다.

## 자동 검사

- AnyCPU 빌드: 자동 검사 45개 통과.
- x86 빌드: 자동 검사 45개 통과. 실행한 Windows는 64비트 환경이며, 32비트 Windows 실기기 검증과 구분합니다.
- 실제 Windows API 검사 포함: 53개 통과. 실제 마지막 입력 조회와 단축키 등록·충돌 보존·변경·해제 포함.
- Windows PowerShell 5.1과 PowerShell 7에서 검사 스크립트 실행 확인.
- 가상 장치로 30초 경계·중복 동작·실제 입력 후 대기·키가 눌린 상태·잠금·원격 연결 해제·절전·보안 화면·복귀 직후 대기·실패 시 해제를 검사.
- 설정 파일 실제 저장·교체·잠긴 파일·저장 실패 후 원본 유지·임시 파일 정리·손상된 설정·기존 버전 호환 검사.
- 테스트 실행 파일은 입력 합성 코드를 호출하지 않습니다. 실제 자동 마우스 동작 확인은 아래의 별도 수동 UI 검증 범위입니다.

## 실제 Windows UI 검증

2026-10-31 로컬 대화형 Windows 세션에서 확인합니다. 자동 확인과 실제 화면 확인을 구분합니다.

- 한글 설정 화면과 단축키 변경 대화상자 표시 확인.
- 기본 30초 간격으로 실제 마우스 동작 횟수가 증가함을 확인.
- Ctrl+Alt+F8 중지 확인.
- Ctrl+Alt+Shift+F8로 변경·저장한 뒤 시작·중지 확인.
- 종료·재실행 후 사용자 단축키 유지와 꺼짐·미세 이동 초기 상태 확인.
- 기본값 복원 및 저장 확인. 검증 후 원래 기본값과 꺼짐 상태로 복원.
- 정보 창의 버전과 EXE에 포함된 MIT 라이선스 표시 확인.
- 설정 창 최소화 및 EXE 재실행으로 기존 창 복귀 확인. 재실행으로 두 번째 설정 창을 만들지 않음.

작은 상태 표시창은 도구 창이라 화면 확인 도구의 독립 창 목록에 나타나지 않습니다. 최소화한 설정 창 대신 표시창 자체를 대상으로 한 캡처는 아직 확인하지 못했습니다.

## 배포 검사와 남은 범위

`package.ps1`과 `verify-package.ps1`은 공개 파일 목록과 ZIP 내 모든 파일 내용, SHA-256을 확인합니다. 소스 ZIP에는 로컬 작업·개인 설정·검사 로그·기존 워드프레스 프로젝트·인증 파일을 포함하지 않습니다.

공개 소스 ZIP을 별도의 한글·공백 경로에 풀어 AnyCPU와 x86 빌드 및 각 45개 자동 검사를 다시 통과했습니다. 원래 작업 폴더의 빌드 산출물이나 비공개 파일에 의존하지 않는지 확인한 검사입니다.

- GitHub Actions의 Windows AnyCPU/x86 빌드·자동 검사와 배포 ZIP 검사를 실제로 통과했습니다. [확인한 실행 결과](https://github.com/holizero/screen-keeper/actions/runs/41172321597)를 참조하세요.
- 실제 화면 보호기 시작 시간과 장시간 동작, 실제 잠금·원격 세션·수동 절전 복귀, 다양한 DPI/다중 모니터/독점 전체 화면은 전부 실기기 검증한 상태가 아닙니다.
- ARM64 네이티브 빌드와 실기기는 검증하지 않았습니다.
- 코드 서명과 배포 사이트의 평판 등록은 하지 않았습니다. 보호 기능 해제나 경고 우회를 요구하지 않습니다.
- 공개 저장소에는 **이 소스 프로젝트만** 올리고, 일반 사용자에게는 단일 EXE 또는 실행 ZIP을 제공합니다.
