# 개발과 검증


Windows와 .NET Framework의 기본 C# 컴파일러를 사용합니다. NuGet 패키지나 외부 라이브러리를 다운로드하지 않습니다. Windows PowerShell 5.1 또는 PowerShell 7에서 실행합니다.

```powershell
.\build.ps1
.\test.ps1
.\test.ps1 -Platform x86
.\test.ps1 -Native
.\package.ps1
```

- `build.ps1`: `build/화면지킴이.exe`와 독립 검사 실행 파일 생성.
- `test.ps1`: 가상 시간·전원·입력 장치를 사용한 회귀 검사와 실제 설정 파일 저장 검사. 실제 마우스·키보드 입력을 보내지 않음.
- `-Native`: 현재 세션의 전역 단축키 두 조합을 잠시 등록해 충돌·변경·해제를 추가 확인. 실제 입력은 보내지 않음. 대화형 Windows 세션의 API 접근 권한이 필요하며, 검사 후 모두 해제.
- `package.ps1`: 검사 후 명시된 공개 파일만 담은 실행 ZIP, 소스 ZIP, 단일 EXE, SHA-256 목록을 `dist/v1.0.0/`에 생성.
- GitHub Actions는 Windows에서 AnyCPU/x86 빌드와 자동 검사를 수행하고 배포 자료를 아티팩트로 보관합니다. 공개 Release를 자동 발행하지 않습니다.

검증 범위와 수동 확인 항목은 [검증 문서](검증.md), 변경 내용은 [변경 기록](../CHANGELOG.md)을 참조하세요.

## 문제 해결

- **단축키 등록 실패**: 다른 앱이 같은 조합을 사용할 수 있습니다. 설정에서 조합을 변경하세요.
- **이미 실행 중**: EXE를 다시 열면 기존 설정 창을 표시합니다. 동시에 여러 인스턴스를 실행하지 않습니다.
- **설정 저장 실패**: 위 설정 경로의 쓰기 권한을 확인하세요. 기존 설정 파일은 잘라 쓰지 않고 임시 파일을 교체하는 방식으로 보존합니다.
- **화면 보호기가 먼저 실행됨**: 앱 간격을 실제 화면 보호기 대기 시간보다 짧게 설정하세요. 이미 잠긴 화면을 해제하는 앱은 아닙니다.
