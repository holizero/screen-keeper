화면지킴이 1.0.0

화면지킴이.exe 하나만 실행하세요. Windows 10/11과 .NET Framework 4.8 이상이 필요합니다.
소스, .NET SDK, PowerShell은 실행에 필요하지 않습니다. 설치 및 관리자 권한을 요구하지 않습니다.

1. 간격(기본 30초)과 동작 방식을 선택하고 '시작'을 누릅니다.
2. 해당 시간 동안 입력이 없으면 동작합니다. 입력하면 대기 시간을 다시 계산합니다.
3. 기본 방식은 마우스를 1픽셀 움직였다가 복귀하는 방식입니다.
   클릭 방식은 포인터 아래의 버튼이나 링크를 실제로 누를 수 있습니다.
4. Ctrl+Alt+F8을 누르면 켜거나 끕니다. 다른 앱이나 숨긴 창에서도 작동합니다.
   '켜기·끄기 단축키 → 변경 → 적용'으로 바꾸고 저장할 수 있습니다.
5. 실행 중 항상 위 상태 표시창이 보입니다. 글씨를 끌어 위치를 옮길 수 있습니다.
   설정 창을 최소화해도 표시창은 유지됩니다. 표시창에서 바로 중지할 수 있습니다.
6. '종료'나 설정 창의 X를 누르면 앱을 완전히 종료합니다.
   EXE를 다시 열거나 알림 영역 아이콘을 두 번 누르면 기존 설정 창을 엽니다.

설정은 %LOCALAPPDATA%\ScreenKeeper\settings.txt에 저장됩니다.
간격과 단축키만 저장하며, 다시 실행할 때는 꺼짐 및 미세 이동 상태로 시작합니다.
프로그램은 네트워크에 연결하지 않고 사용 기록을 저장하지 않습니다.
잠금·연결 해제·절전·보안 화면에서는 일시 대기하고 복귀 후 시간을 다시 계산합니다.
수동 잠금·절전이나 조직 정책을 변경하지 않습니다.
중지 시 전원 유지 요청을 해제하고, 종료 시 등록한 단축키도 해제합니다.
보안 화면·독점 전체 화면 위 표시는 보장하지 않습니다.
실행 중 배터리 사용량이 늘 수 있으므로 사용 후 중지하세요.

배포본은 코드 서명되지 않았습니다. SHA256SUMS.txt의 값과 파일 해시를 비교할 수 있습니다.
보안 경고를 우회하거나 보호 기능을 끄지 마세요.
코드와 아이콘은 MIT 라이선스에 따라 배포됩니다. EXE 안에도 라이선스를 포함하며 '정보' 버튼에서 확인할 수 있습니다.
