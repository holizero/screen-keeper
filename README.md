# 화면지킴이

입력이 없을 때 기본 30초마다 마우스를 미세하게 움직여 화면 보호기 실행을 방지하는 Windows 앱입니다. 화면 꺼짐·자동 절전 방지와 사용자 지정 단축키를 지원합니다.

최초 공개 버전: **1.0.0**

## 다운로드

GitHub Releases에서 `화면지킴이.exe` 하나를 내려받아 실행합니다. 설치와 관리자 권한이 필요하지 않습니다. Windows 10/11과 .NET Framework 4.8 이상이 필요합니다.

## 소개와 사용법

워드프레스 소개글을 준비 중입니다. 글을 초안으로 저장한 뒤 이곳에 해당 글의 사용법 링크를 연결합니다.

기본 사용: 앱에서 **시작**을 누르거나 **Ctrl+Alt+F8**로 켜고 끕니다. 단축키 옆 **변경**에서 조합을 바꿀 수 있습니다. 앱은 꺼짐과 미세 이동 방식으로 시작합니다. 선택적 클릭 방식은 포인터 아래 버튼·링크를 실제로 누를 수 있습니다.
