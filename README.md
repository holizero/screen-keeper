# 화면지킴이

입력이 없을 때 기본 30초마다 마우스를 미세하게 움직여 화면 보호기 실행을 방지하는 Windows 앱입니다. 화면 꺼짐·자동 절전 방지와 사용자 지정 단축키를 지원합니다.

최초 공개 버전: **1.0.0**

## 다운로드

[화면지킴이 1.0.0 다운로드](https://github.com/holizero/screen-keeper/releases/tag/v1.0.0)에서 단일 실행 파일 `ScreenKeeper.exe`를 내려받아 실행합니다. Windows ZIP 안의 `화면지킴이.exe`와 동일한 파일입니다. 설치와 관리자 권한이 필요하지 않습니다. Windows 10/11과 .NET Framework 4.8 이상이 필요합니다.

## 소개와 사용법

**[워드프레스 소개·자세한 사용법](https://mntkim.com/screen-keeper/)**

실제 프로그램 캡처와 함께 실행 방법, 동작 방식, 단축키 변경과 상태 표시를 설명합니다. [English guide](https://mntkim.com/en/screen-keeper/)도 제공합니다.

기본 사용: 앱에서 **시작**을 누르거나 **Ctrl+Alt+F8**로 켜고 끕니다. 단축키 옆 **변경**에서 조합을 바꿀 수 있습니다. 앱은 꺼짐과 미세 이동 방식으로 시작합니다. 선택적 클릭 방식은 포인터 아래 버튼·링크를 실제로 누를 수 있습니다.

앱에는 네트워크 통신·추적·자동 업데이트가 없습니다. 실행 중 배터리 소모가 늘 수 있습니다. 시스템과 조직의 잠금 정책은 변경하지 않습니다. 배포본은 코드 서명되지 않았으며 보안 보호 기능 해제나 경고 우회를 요구하지 않습니다.
